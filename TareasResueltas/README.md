# Tareas Resueltas

Esta carpeta contiene tareas resueltas y ejemplos adicionales del curso de Programacion 2.

El objetivo es que los estudiantes puedan revisar soluciones, comparar enfoques y estudiar codigo ya trabajado en clase.

## Organizacion

Las tareas se organizaran por semana.

```text
TareasResueltas/
Semana2/
```

## Indice

### Semana 2

- `Semana2/ConversorMaya.cpp`: version en C++.
- `Semana2/ConversorMaya.cs`: version en C#.

## Recomendaciones

- Leer primero el enunciado o contexto de la tarea si esta disponible.
- Revisar el codigo antes de ejecutarlo.
- Comparar las diferencias entre versiones cuando exista el mismo ejercicio en varios lenguajes.
- No subir archivos generados automaticamente por el sistema operativo o compiladores.
