Proyecto BlueJ: Hola Mundo BlueJ

Curso: Programacion 2
Universidad Mariano Galvez, sede Portales

Objetivo:
Mostrar un ejemplo muy simple de POO con Animal y Perro.

Clases:
- Animal: clase base con nombre y sonido generico.
- Perro: clase hija que hereda de Animal.
- Simulador: crea un perro y muestra los datos en consola.

Para probar en BlueJ:
1. Abrir esta carpeta como proyecto BlueJ.
2. Presionar Compile.
3. Clic derecho sobre Simulador.
4. Ejecutar void main(String[] args).
5. Presionar OK.
6. Revisar la salida en la terminal.

Conceptos:
- Clase
- Objeto
- Herencia
- Sobrescritura de metodos

Nota:
Los archivos .class aparecen al compilar, pero no forman parte del codigo fuente.
